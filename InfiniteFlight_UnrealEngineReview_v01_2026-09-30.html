Should InfiniteFlight move to Unreal Engine?

InfiniteFlight today is one 4,346-line HTML file built on Three.js. It runs in any browser, it's hosted on aiquorum.org, and it reads the SideWinder stick through the browser's built-in Gamepad API. This page compares that with rebuilding in Unreal Engine 5, and lists the questions only you can answer.

My recommendation is to stay on Three.js for now.

Unreal would look much better, but it can't run inside a browser, it has weak support for generic joysticks on a Mac, and most of the work happens in a visual editor that Claude can't drive well. Moving would mean starting over. It only makes sense if you decide InfiniteFlight is a Mac desktop app for you alone and looks matter more than anything else.

How each one reaches a player

The biggest difference is where the game runs

Epic removed Unreal's HTML5 export in version 4.24. Pixel Streaming is Epic's official browser route today. Third-party WebGPU ports exist but are experimental.

Pros and cons

What Unreal would give you, and what it would cost

Pros

  • The graphics are in a different league: realistic lighting, clouds, water and shadows come built in.
  • Cesium for Unreal is free and streams the whole real Earth, so Yosemite would be one of thousands of real places.
  • Epic runs a flight-sim effort (the Antoinette Project), and pilots have built VR flight sims with Cesium for Unreal.
  • It's free to use. Epic takes 5% only after a game earns over $1 million, which won't apply here.
  • UE 5.8 (June 2026) runs natively on Apple Silicon, and your M2 Max with 32 GB can run the editor.

Cons

  • It can't run in a browser, so aiquorum.org/flight, the iPhone version and the planned leaderboards would need a different design.
  • Unreal's flight-stick plugin (RawInput) is Windows-only. On a Mac, forum reports say generic HID joysticks like the SideWinder are hit or miss.
  • Most Unreal work is clicking in a large editor and wiring visual "Blueprints", which are binary files. Claude can write Unreal C++, but it can't see or edit the editor the way it edits index.html.
  • Everything gets rebuilt: the seven aircraft, eight maps, HUD, autopilot, calibration wizard and physics.
  • Mac developers report UE 5.6 and 5.7 failing to compile on macOS 26.1 with Xcode 26. Your Mac runs macOS 26.4.
  • You have 84 GB free on this Mac. The engine plus Xcode needs tens of gigabytes, and projects grow quickly. I couldn't confirm an exact install size.
  • Epic has said 5.8 is the last planned UE5 release before UE6, so a big engine change is coming.
